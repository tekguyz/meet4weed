# Push text names no member and no sesh

A web push is rendered by the operating system on a locked screen, in front of
whoever is holding the phone. "Dana approved your RSVP for Thursday Smoke Sesh"
outs both people to a stranger, a landlord or an employer, which is the exact
harm this app's fuzzy locations and host-approved RSVPs exist to prevent.

Push text is therefore deliberately plain — "Meet4Weed: you have an update" —
and tapping it opens the in-app feed, which is behind auth and is the source of
truth anyway (spec §8). Reminders may be slightly richer, e.g. "A sesh starts
tomorrow", because they name nobody.

## Consequences

This is a deliberate deviation from the obvious path, so it will look like an
unfinished feature to a future reader and somebody will try to "fix" it. It is
not unfinished. The visual design carries no such restraint — icons, splash and
feed are held to the `impeccable` bar.
